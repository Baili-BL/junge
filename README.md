# 钧哥天下无双 - 股票推荐系统

基于"钧哥天下无双低吸策略"的量化选股系统，每日自动分析并推荐符合条件的主板股票。

## 📊 策略核心

**优先级排序**: 题材主线 > 技术突破 > 商业模式 > 财务分析

### 核心量化标准

#### 1. 资金流入维度（最重要）
- 连续3日主力资金净流入
- 单日净流入规模达3%涨幅
- 机构净买入占比 >25%
- 龙虎榜连续3日加仓

#### 2. 成交量维度
- 首日放量 100%-300%
- 次日温和放大 20%-50%
- 量价齐升，避免无量空涨

#### 3. 涨幅维度
- 龙头股实现2连板+
- 封单/流通市值 ≥5%
- 中军大盘股放量涨5%+

### 关键纪律
- ⏰ 题材3天不发酵即切换
- 📊 仅限主板股票(60/00开头)
- 💰 低吸为主，回调介入

## 🚀 快速开始

### 方式一：Windows批处理启动
双击 `start.bat` 自动安装依赖并启动

### 方式二：Python脚本启动
```bash
python run.py
```

### 方式三：手动启动

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **运行分析（命令行）**
```bash
python stock_analyzer.py
```

3. **启动Web服务**
```bash
python app.py
```

4. **访问系统**
打开浏览器访问: http://localhost:5000

## 🔧 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/recommendations` | GET | 获取推荐股票 |
| `/api/recommendations?refresh=true` | GET | 强制刷新推荐 |
| `/api/hot_sectors` | GET | 获取热门板块 |
| `/api/stock/<code>` | GET | 获取股票详情 |
| `/api/strategy` | GET | 获取策略说明 |
| `/api/status` | GET | 获取系统状态 |

## 📈 功能特点

1. **智能选股**
   - 自动获取热门板块资金流向
   - 量化分析主板股票
   - 综合评分排序推荐

2. **实时数据**
   - 基于akshare获取A股实时数据
   - 自动缓存避免重复请求
   - 支持手动刷新更新

3. **美观界面**
   - 赛博朋克风格UI设计
   - 响应式布局适配移动端
   - 动态动画效果

4. **风险提示**
   - 自动计算止损位
   - 显示技术指标状态
   - 题材失败信号提醒
